# Скрипты инициализации БД

Эта папка монтируется в контейнер как `/docker-entrypoint-initdb.d`
(см. `docker-compose.yml`).

Скрипты выполняются **один раз — только при первом старте**, когда том с данными
(`cryptodb_pgdata`) ещё пуст, и в алфавитном порядке. Поддерживаются `.sql`,
`.sql.gz` и `.sh`.

Примеры файлов:

```
00-extensions.sql      # CREATE EXTENSION IF NOT EXISTS …
10-seed-demo.sql       # стартовые данные, если нужны
```

Повторно они сами не выполнятся: для полного сброса БД нужно удалить том данных —
`docker compose down -v` (**удаляет все данные, необратимо**).

Эволюционные изменения схемы после первого старта ведутся через `../migrations`.
