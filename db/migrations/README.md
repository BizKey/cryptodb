# Миграции базы данных

Здесь размещаются **эволюционные SQL-миграции** — изменения схемы, применяемые по порядку во времени.

## Именование файлов

```
V<номер>__<краткое_описание>.sql
```

Примеры:

```
V001__init.sql
V002__add_users.sql
V003__create_crypto_prices.sql
```

Правила:

- префикс `V` + уникальный возрастающий номер + `__` + описание латиницей в snake_case;
- номер версии не меняется после применения миграции;
- уже применённую миграцию **не редактируем** — для изменений создаём новую;
- каждая миграция применяется ровно один раз.

## Инструмент применения

Конкретный инструмент (Flyway / Liquibase / goose / golang-migrate и т. п.) ещё не выбран.
Соглашение об именовании выбрано так, чтобы файлы легко адаптировались под выбранный инструмент.
